PLANETA VINTAGE - SITIO WEB ESTÁTICO
=====================================

ESTRUCTURA DE ARCHIVOS:
-----------------------
- index.html          - Página principal con hero, colecciones y destacados
- nosotros.html       - Información sobre el equipo, visión, misión y contacto
- destacados.html     - Catálogo de productos destacados
- hombre.html         - Colección de ropa para hombre
- mujer.html          - Colección de ropa para mujer
- estilos.css         - Todos los estilos del sitio
- scripts.js          - JavaScript para menú móvil y filtros
- imagenes/           - Carpeta con todas las imágenes del sitio

COLORES PRINCIPALES:
--------------------
- Naranja Quemado: #e86e51
- Verde Vintage: #64a96d
- Amarillo Pastel: #f4d37b
- Beige Claro: #f7f3e9
- Negro: #000000
- Blanco: #ffffff

FUENTES:
--------
- Montserrat (sans-serif)

CARACTERÍSTICAS:
----------------
✓ Diseño responsive (móvil y escritorio)
✓ Menú de navegación con versión móvil
✓ Secciones de colecciones con efectos hover
✓ Catálogos de productos con filtros por categoría
✓ Formulario de contacto funcional
✓ Footer con información de contacto y redes sociales
✓ Efectos visuales con sombras de colores
✓ Imágenes de fondo decorativas

NAVEGACIÓN:
-----------
INICIO → Página principal con hero y colecciones
NOSOTROS → Información del equipo y formulario de contacto
DESTACADOS → Productos destacados del catálogo
HOMBRE → Colección masculina con filtros
MUJER → Colección femenina con filtros

IMÁGENES NECESARIAS:
--------------------
Asegúrate de tener todas las imágenes en la carpeta "imagenes/":
- logo-header.png
- planeta-vintage-logo.png
- hero-background.webp
- smiley-face.png
- laptop-hands.png
- recurso-10.png
- hombre-vintage.png
- mujer-vintage.png
- globe-icon.png
- tiktok-icon.png
- instagram-icon.png
- Imágenes de productos (.webp)

INSTRUCCIONES DE USO:
---------------------
1. Coloca todos los archivos HTML, CSS y JS en la carpeta "Planeta vintage"
2. Crea una subcarpeta llamada "imagenes" y coloca todas las imágenes allí
3. Abre index.html en tu navegador para ver el sitio
4. El sitio es totalmente funcional sin necesidad de servidor

NOTAS TÉCNICAS:
---------------
- Los filtros de categorías funcionan con JavaScript
- El formulario de contacto muestra una alerta (conectar a backend si es necesario)
- Todas las rutas de imágenes son relativas
- Compatible con todos los navegadores modernos
